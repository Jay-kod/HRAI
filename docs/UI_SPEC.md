# UI Specification

- Mobile-first from 360px, with minimum 16px body text and an 8px spacing rhythm.
- Risk levels must be communicated with text, icon, and colour; never colour alone.
- The check-in uses four stages: measurements, lifestyle, medical history, and review.
- Result pages show overall risk, three condition cards, factors, grouped recommendations, engine status, and disclaimer.
- Dashboard charts use Chart.js and provide empty states.
- Reports hide navigation when printed.
